# 메디버디 메신저

병원 · 의원 안에서 쓰는 원내 메신저입니다. 원내 PC 한 대에 서버를 두고, 직원 PC 끼리 대화 · 파일 · 공지를 주고받습니다. 대화와 파일은 병원 안 서버에만 저장되고 바깥 서버를 거치지 않습니다.

## 지금 상태

첫 공개 판을 준비하고 있습니다. 공개되면 이 저장소의 **Releases** 에 설치 파일이 올라옵니다.

## 설치(첫 공개 뒤)

| 어디에 | 무엇을 |
|---|---|
| 서버 PC(원내 PC 한 대 · 늘 켜 두는 PC) | 「메디버디 메신저 서버」 설치 파일 |
| 직원 PC | 「메디버디 메신저」 설치 파일 — 처음 켤 때 서버 주소를 넣고 내 이름을 고르면 됩니다 |

- 윈도 10 · 11(64비트)에서 돌아갑니다. 따로 깔아야 하는 프로그램은 없습니다.
- 서버 주소는 서버 PC 의 관리자 화면에 보입니다.

## 설치할 때 Windows 경고가 보일 수 있어요

메디버디 메신저 설치 파일에는 아직 **코드 서명 인증서**(해마다 비용이 드는 유료 인증서)를 붙이지 않았습니다. 그래서 Windows 가 「게시자를 확인할 수 없다」는 경고를 보여 줄 수 있습니다.

이 경고는 **프로그램에서 문제가 발견됐다는 뜻이 아닙니다.** Windows 가 처음 보는 프로그램이라 만든 곳을 확인하지 못했다는 뜻입니다. 경고는 처음 설치할 때만 보이고, 이후 자동 업데이트는 이 창 없이 진행됩니다.

| 언제 | 보이는 창 | 이어서 설치하기 |
|---|---|---|
| 브라우저(Edge · Chrome)로 받을 때 | 「일반적으로 다운로드되지 않는 파일」 같은 알림 | 내려받기 목록에서 **[유지]** 또는 **[계속]** 고르기 |
| 설치 파일을 열 때 | 파란 「Windows의 PC 보호」 창 | **[추가 정보]** → **[실행]** |
| 서버를 설치할 때 | 「사용자 계정 컨트롤」 창(게시자: 알 수 없음) | 프로그램 이름을 확인한 뒤 **[예]** |

### 안심하고 설치하는 방법

1. **이 저장소의 Releases 에서만 받으세요.** 다른 곳에 올라온 파일은 쓰지 않는 것이 안전합니다.
2. **받은 파일이 올린 파일과 같은지 확인하세요.** Release 마다 파일의 SHA-256 값을 함께 올립니다. 받은 폴더에서 PowerShell 을 열고 아래처럼 하면 값이 나옵니다. 두 값이 같으면 중간에 바뀌지 않은 파일입니다.
   ```powershell
   Get-FileHash .\MediBuddy-Setup-3.1.0.exe -Algorithm SHA256
   ```
3. 원하면 [VirusTotal](https://www.virustotal.com) 에 파일을 올려 여러 백신으로 한 번에 검사해 볼 수 있습니다.

### 이 프로그램이 하는 일

- **직원 PC**: 관리자 권한 없이 그 PC 의 내 계정에만 설치됩니다. 지울 때는 Windows 「설정 › 앱 › 설치된 앱」에서 「메디버디 메신저」를 제거하면 됩니다.
- **서버 PC**: PC 를 켜면 함께 켜지는 Windows 서비스로 설치되고, 직원 PC 가 접속할 수 있게 방화벽에서 메신저 포트(48453) 하나를 같은 병원 망에만 엽니다. 그래서 설치할 때 관리자 권한을 묻습니다.
- 대화와 파일은 병원 서버에만 저장됩니다. 바깥으로 보내는 것은 없고, 업데이트를 확인할 때도 이 저장소의 안내 파일을 읽기만 합니다.

코드 서명 인증서를 붙이면 위 경고가 줄어듭니다. 붙이게 되면 이곳에 알리겠습니다.

## 업데이트

- 새 판이 올라오면 병원 서버가 스스로 받아 설치하고, 직원 PC 는 병원 서버에서 자동으로 받습니다.
- 업데이트 안내는 서명해서 올립니다. 병원 서버는 서명이 맞을 때만 설치합니다.
- 업데이트를 확인할 때 병원 서버가 이곳에 보내는 것은 없습니다(판 안내 파일만 읽습니다).

## 알아 두기

- 이 저장소에는 설치 파일만 올라오고 소스는 없습니다.
- 이용 조건은 첫 공개 때 함께 올립니다.
